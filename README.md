## 📝 About

**CollabCode** is a real-time collaborative code editor that allows multiple developers to edit the same code simultaneously, similar to Google Docs but for code.

## ✨ Features

| Feature | Status |
|---------|--------|
| Real-time code sync | ✅ Working |
| Multiple file support | ✅ Working |
| Monaco Editor (VS Code) | ✅ Working |
| Room-based collaboration | ✅ Working |
| User presence | ✅ Working |
| PostgreSQL persistence | ✅ Working |

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React 18, Monaco Editor |
| Backend | FastAPI (Python) |
| Database | PostgreSQL (Neon) |
| Real-time | HTTP Polling |
| Deployment | Vercel + Render |

## 🚀 How to Use

1. **Create a room** - Enter your name and click "Create New Room"
2. **Share the Room ID** - Copy the 8-character Room ID
3. **Collaborate** - Share the link with others to code together
